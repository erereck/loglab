# LogLab

Um site estático de logging de games inspirado na categoria de sites de backlog — com decisões de interface questionáveis preservadas como parte do projeto.

## Rodar localmente

Abra `index.html` diretamente ou sirva a pasta com qualquer servidor HTTP simples.

## Dados

Login, conta, logs e posições do perfil são fictícios e ficam apenas no `localStorage` / `sessionStorage` do navegador. Não use uma senha real.

## GitHub Pages

O workflow em `.github/workflows/pages.yml` publica a branch `main` usando GitHub Pages.
